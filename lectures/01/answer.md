## 宿題

- 取り組んだレベル：基礎
- やったこと：`uv run python -m app.ask`を用いて、3つの異なるモデルに「LoRAとは何ですか？」という同じ質問を入力した。環境変数`AIE_MODEL`を変更してモデルを切り替え、回答内容と入出力トークン数を比較した。
- 結果：3つのモデルともLoRAの基本的な意味やメリットを説明できていた。gemini-3.5-flash-liteは初心者向けの例え話が中心だったが、gemini-3.5-flashとgemini-3.8-flashは低ランク行列を用いる仕組みにも言及していた。出力トークン数はそれぞれ836、746であり、gemini-3.8-flashの方が簡潔だった。gemini-3.5-flash-liteではトークン数が表示されなかった。
- 気づき・疑問：同じ質問でもモデルによって説明の詳しさや内容が異なり、出力が長いほど正確で詳しいとは限らないことが分かった。また、どのモデルも例え話を多く用いていたため、技術的な仕組みを理解するには数式を用いた説明を求める必要があると感じた。特に、LoRAで低ランク行列を用いても十分な学習効果が得られる理由が気になった。
